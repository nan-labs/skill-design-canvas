# Changelog

## 0.2.0 — 2026-10-23

First public release, as a standalone skill.

- Tool-neutral rules for shared design canvases: new rows only, no edits or deletes without asking, no overlaps on a complete live read, decision marks left to humans.
- Notes guidance: notes record the ask, the change and who decided, not specs.
- Comment workflow: read first, reply before resolving, resolve only once verified.
- Page housekeeping (soft range 60–80 boards, Contents board), proposed to the user, never silent.
- Optional reference mapping the rules onto Paper as one example tool.
- Claude Code plugin and marketplace manifests.
